# NutriVida

Landing page responsiva para apresentação de serviços de nutrição, desenvolvida com HTML e CSS.

## Sobre o projeto

O NutriVida é um projeto front-end criado para apresentar uma página institucional de uma profissional de nutrição. A página reúne apresentação profissional, serviços oferecidos, benefícios, depoimentos e formulário de contato.

O foco do projeto está na construção de uma interface simples, organizada e responsiva utilizando tecnologias web fundamentais.

## Funcionalidades

- Seção principal com chamada para ação
- Apresentação profissional
- Exibição de serviços oferecidos
- Seção de benefícios
- Depoimentos
- Formulário de contato
- Layout responsivo
- Tipografia externa via Google Fonts

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (arquivo preparado para futuras interações)
- Google Fonts
- Replit
- Git
- GitHub

## Como executar

Por ser um projeto estático, não é necessário instalar dependências.

### 1. Clone o repositório

```bash
git clone https://github.com/diegobluz/NutriVida.git
cd NutriVida
```

### 2. Abra a aplicação

Abra o arquivo `index.html` diretamente no navegador.

Também é possível utilizar extensões como Live Server no VS Code para executar o projeto localmente.
